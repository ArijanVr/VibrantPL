# Sicherheit

## Unterstützte Versionen

| Version | Unterstützt |
|---|---|

## Schwachstellen melden

Bitte **keine** öffentlichen Issues für Sicherheitslücken.

1. Nutze [GitHub Security Advisories](https://github.com/ArijanVr/VibrantPL/security/advisories/new) (Private vulnerability reporting), oder
2. kontaktiere ARJO LAB über die Website arjolab.ch.

Wir bestätigen den Eingang in der Regel innerhalb von 14 Tagen.

## Umfang

Vibrant+ speichert Daten lokal, hat keine Telemetrie und keine Konten. Netzwerkziele (Wetter, Cover, Wechselkurse, optionale Downloads) sind in der README aufgeführt.
